# 技术选型

[文档中心](README.md) · [实现说明](implementation.md) · [开发指南](development.md)

## 已采用技术

| 层次       | 技术                              | 用途                                      |
| ---------- | --------------------------------- | ----------------------------------------- |
| 前端       | Vue 3、TypeScript、Vite           | 页面、类型和构建                          |
| 组件与状态 | Naive UI、Vue Router、Pinia       | 控件、路由和会话状态                      |
| 后端       | Go、Gin                           | HTTP JSON API、认证授权和任务执行         |
| 数据库     | PostgreSQL、GORM                  | 配置、Session、资源快照、任务及审计持久化 |
| 迁移       | golang-migrate                    | 内嵌的版本化 SQL，不使用 AutoMigrate      |
| 云接入     | 腾讯云和阿里云官方 Go SDK         | 国内站及国际站接口请求、签名和错误处理    |
| OAuth2     | `golang.org/x/oauth2`             | 授权码、PKCE 和令牌交换                   |
| 应用日志   | 标准库 `log/slog`                 | 标准输出 JSON 日志                        |
| 部署       | Linux、Docker Compose、外置 Nginx | 应用与数据库运行、HTTPS 访问              |

构建工具及锁定版本见 [开发指南](development.md)。发布程序内嵌前端，API 和 Worker 默认在同一进程运行，也可分别使用 `api`、`worker` 命令。

## 应用结构

采用模块化单体，共用数据库。`Cloud` 接口承接产品类型、地域发现、资源查询、监控和服务器操作，路由器按账号厂商选择适配器。厂商指标名称、端点、分页和批量上限留在适配层。

资源由云账号、类型、地域和云端实例 ID 标识。服务器与数据库复用授权、快照、缓存和任务；数据库专有配置使用明确字段保存，服务器操作仅对服务器开放。后续 LB 观测另行确认，不提前引入插件框架或通用指标引擎。

## 登录与授权

Session 保存在 PostgreSQL。Cookie 使用 HttpOnly、SameSite，服务端只保存随机令牌的 SHA-256 摘要；写请求校验来源和 CSRF Token。密码使用 bcrypt 哈希。

第三方身份必须绑定管理员创建的已有账号。首次第三方授权后进入绑定向导，使用本地账号密码验证及单独的 CSRF 校验；5 分钟有效的绑定凭证单次消费，身份关联、审计和登录会话在同一事务提交。端点和用户标识字段可配置，禁止按同名或邮箱自动关联。权限来自本地用户角色，具体身份平台的专有协议需另行联调。

同一角色的功能权限和资源范围共同生效，再合并多角色结果。后端校验云账号、资源类型、地域和实例范围，强制操作具有独立权限点。

## 凭证与主密钥

云密钥和 OAuth2 Client Secret 使用 AES-256-GCM 加密后存入数据库。主密钥为首次初始化生成的 32 字节文件，由部署路径注入。已有校验记录或加密数据时禁止生成替代密钥，密钥不匹配则拒绝启动。

数据库和主密钥分别备份、配套恢复。当前没有自动轮换工具。密码、云密钥和令牌不进入日志或版本控制。

## 同步与操作

页面只读 PostgreSQL 快照，监控采样偏旧时提示，默认阈值 10 分钟，可手动调整。列表刷新当前页，详情刷新单台，任务保存逐实例结果，失败项保留旧数据并可重试。Worker 按账号领取任务，账号内最多并发处理 4 个地域、产品组，继续复用云适配层的分批监控查询。

服务器操作先持久化任务和审计，再调用云端。行锁、租约和活跃任务唯一索引限制重复执行。结果不明时只核对状态，不自动重复提交。数据库同步按产品查询 CPU、内存、存储空间和连接数，不执行变更操作。

## 当前边界

仅展示当前监控数据，不提供历史趋势或采集 Agent。数据库仅支持 MySQL、PostgreSQL 只读观测。资源列表在应用内过滤、排序和分页，后续按实际规模评估查询优化。真实云账号、国际站、身份平台和部署环境的可用性以实际联调为准。
