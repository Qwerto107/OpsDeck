# 更新记录

[文档中心](README.md) · [下载版本](https://github.com/Qwerto107/OpsDeck/releases)

版本标签推送后由 GitHub Actions 构建。程序附件、镜像和 Release 是否可用，以工作流结果及 Releases 页面为准。

## v0.1.2

- 接入阿里云 ECS 和轻量应用服务器，增加阿里云国际站、腾讯云国际站。
- 云账号页面统一提供 4 个云厂商选项，地域只显示发现数量。
- 增加 MySQL、PostgreSQL 数据库资源列表和详情，只读展示配置、标签及连接地址。
- 复用账号同步、权限范围和缓存，数据库在 API、Worker 和适配层禁止服务器操作。
- 修复实例详情页格式检查导致的构建失败。
- 调整项目定位与介绍文案。
- 参照 QPix 的首页、文档中心及分主题指南结构整理文档，不包含界面截图。

升级需先运行 `migrate`，旧账号默认国内站。已有云账号需补齐数据库查询权限，见 [腾讯云 CAM](tencent-cam.md)、[阿里云 RAM](alibaba-ram.md) 和 [数据库资源展示](database-resources.md)。

## v0.1.1

- 云监控按产品、地域和指标批量查询，账号内限制地域并发。
- 页面读取 3 分钟有效期的快照，手动更新同步，更新时间显示在按钮旁。
- 增加云账号、用户和角色硬删除及对象保护。
- 审计操作使用中文展示。
- 调整服务器开机、关机、重启按钮，弹框提供强制选项及“确认”输入校验。

该标签的前端格式检查未通过，详情页格式修复包含在 v0.1.2。不要仅凭标签存在判断产物已经发布。

## v0.1.0

- 提供腾讯云 CVM、Lighthouse 资源展示、当前监控和单台操作。
- 支持密码登录、通用 OAuth2 绑定、用户角色及资源范围授权。
- 提供 PostgreSQL 任务、审计、系统设置及统一进程启动。
- 增加内嵌前端程序、多平台构建和 GHCR 镜像发布工作流。
