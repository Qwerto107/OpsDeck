# 使用指南

[文档中心](README.md) · [部署指南](deployment.md)

## 首次接入

1. 使用初始化时创建的管理员账号登录。
2. 按 [CAM](tencent-cam.md) 或 [RAM](alibaba-ram.md) 策略配置专用云账号凭证。
3. 在“云账号”选择腾讯云、腾讯云国际站、阿里云或阿里云国际站，填写名称和凭证后启用。
4. 保存后，Worker 自动发现各产品的全部可用地域并同步资源。云账号页面显示地域数量、同步时间和错误。
5. 配置角色的功能权限和资源范围，再分配给用户。预置只读、运维角色初始没有资源范围。

一个平台可接入多个云账号。云账号创建后不能切换厂商或站点；编辑时可保留原凭证或替换凭证。地域无需逐项填写，后续同步会发现新增地域。

## 资源查看与更新

服务器页面展示 CVM、Lighthouse、ECS 和轻量应用服务器。数据库页面展示两家云厂商的 MySQL、PostgreSQL，详细字段见 [数据库资源展示](database-resources.md)。

两个页面均支持搜索、账号、类型、地域和状态筛选。排序支持名称、地域和指定标签键，可组合最多 8 个条件，分别选择方向和优先级。排序先作用于完整授权结果，再分页；空值始终排在末尾。服务器列设置可拖动调整顺序，并保存个人偏好。

资源页面进入和浏览器重载只读取数据库快照。缓存有效期为 3 分钟，过期继续显示旧数据；点击“更新”才请求云端同步。更新时间位于更新按钮旁，多账号显示最早的成功更新时间；任一账号尚未成功同步时，不显示整体缓存有效。

一次同步覆盖对应账号的服务器和数据库。并发刷新同一账号会复用活跃任务，页面轮询任务结果，完成后重新读取快照。关闭页面不会取消任务。后台不定时同步资源，仍执行已入队任务、操作结果核对和日志清理。

## 当前监控

系统设置控制服务器 CPU、内存、磁盘空间和网络入站、出站指标的展示。每项指标显示单位、采样时间和数据状态，超过 5 分钟的采样标记过期。快照缓存时长与云端采样时间分别判断。

平台只调用云监控接口。内存、磁盘空间指标需要云端已有采集数据；平台不会安装 Agent，也不会通过 SSH 补采。无数据、查询失败和过期分别展示，不把缺失值显示为零，不以磁盘 I/O 代替空间使用率。没有挂载点明细时不推测磁盘分区。

当前不提供历史趋势或自动刷新。设置中的兼容字段 `refresh_seconds` 不触发资源同步。

## 服务器操作

停止状态显示“开机”，运行状态显示“关机”和“重启”。实际按钮还受用户权限、云账号启用状态和未完成任务限制。

关机、重启会弹框确认。需要强制操作时，勾选弹框中的“强制关机”或“强制重启”，再在下方输入框填写“确认”。只有具备对应强制权限的用户才能选择。

操作受理后，在实例详情查看结果。请求受理不代表云端已经完成。同一实例只允许一个未完成操作；超时或进程重启后核对云端状态，不自动重复提交。无法确认的操作显示“结果待确认”。

腾讯云普通操作显式使用 `SOFT`，强制操作使用 `HARD`，普通失败不升级为强制。阿里云使用各产品的强制参数；ECS 关机使用 `KeepCharging`，保留计算资源并继续计费。强制操作可能丢失未落盘数据。

## 权限管理

管理员创建用户，分配角色。角色同时包含功能权限和云账号、资源类型、地域、实例范围。功能权限与资源范围必须来自同一角色，再合并不同角色的授权结果。

例如，角色 A 可以重启账号 A，角色 B 只能查看账号 B。持有两个角色的用户仍不能重启账号 B。后端对查询和操作执行同样校验，页面隐藏按钮只是展示。

只读人员默认具备资源和监控查看权限，运维人员增加普通操作权限。两者均需配置资源范围，强制权限需另行授予。数据库沿用 `resources.read` 和 MySQL、PostgreSQL 类型范围，“全部类型”也包含数据库。

用户、非管理员角色和云账号支持硬删除。不能删除当前登录账号、最后一个启用的管理员或管理员角色。删除云账号会移除平台凭证、快照及对应角色范围，保留历史审计；存在未完成任务时拒绝删除。此操作不调用云端销毁接口，也不提供回收站。

## OAuth2 登录

系统设置可添加多个提供方，配置授权、令牌、用户信息端点、Client ID、Client Secret、Scope 和用户唯一标识字段。端点使用 HTTPS，唯一标识支持点分隔字段路径。

1. 管理员在身份平台创建应用。
2. 在 OpsDeck 创建提供方，并把生成的回调地址配置到身份平台。
3. 用户先登录管理员创建的本地账号，在账号安全页主动绑定身份。
4. 绑定成功后，使用登录页的提供方入口登录。

平台使用授权码流程和 PKCE。第三方身份必须关联已有启用账号，不自动创建用户，不按同名或邮箱自动关联。管理员可解绑，解绑后撤销该用户会话。企业微信、钉钉、飞书的专有流程需单独验证，通用 OAuth2 配置不代表已适配其全部登录方式。

## 审计与系统设置

审计页面用中文展示登录、用户、角色、云账号、系统设置及实例操作等事件。记录操作人、来源 IP、时间、目标、结果和请求标识；接口及数据库保留稳定的操作代码。

日志默认保留 180 天，可设为 1 至 3,650 天。缩短保留期需确认，已有日志也按新策略清理；后台每小时执行到期清理。密码、云密钥和访问令牌不会写入审计。

会话默认连续无操作 30 分钟失效，最长 8 小时。可分别设置为 5 至 1,440 分钟、1 至 168 小时。管理员重置密码后交付临时密码，用户下次登录必须修改。
