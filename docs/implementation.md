## 云接入与资源

账号的 `provider` 为 `tencent` 或 `alibaba`，`site` 为 `china` 或 `international`。界面组合成 4 个云厂商选项。创建后禁止修改厂商和站点，版本化迁移为旧账号补充 `china`。

生产入口使用 `NewCloud` 路由到适配器。`Cloud.Kinds` 提供产品类型，Worker 不依赖特定厂商的类型集合。腾讯云国际站按服务选择国际站端点；阿里云使用区域 API，凭证决定账号资源，站点决定地域发现的初始端点。

服务器类型为 `cvm`、`lighthouse`、`ecs`、`sas`。数据库类型为 `mysql`、`postgresql`，专有配置只保存引擎、版本、内存容量和连接地址，不保存 API 可能返回的密码或其他安全配置。

资源列表先应用角色范围、搜索和筛选，再对完整结果排序和分页。服务器页面请求 `category=server`，数据库页面请求 `category=database`。不传分类保留查询全部授权资源的接口行为。

## 授权与删除

同一角色中的功能权限与资源范围共同生效，再合并角色结果，禁止交叉放大。平台管理权限与资源权限分别校验；用户、角色及身份关联管理还检查管理员身份。

云账号、用户和非管理员角色支持硬删除。删除云账号清理凭证、资源快照和角色范围，任务解除对象关联，历史审计保留。有未完成任务时拒绝删除。用户删除撤销会话并清理身份关联，保留审计操作者名称；当前用户、最后一个启用的管理员和管理员角色受到删除保护。

## 首次第三方登录绑定

OAuth 回调对已绑定身份执行登录，对未绑定身份创建 5 分钟的短期请求并跳转绑定向导。绑定凭证只以摘要存入 oauth_bindings，通过 HttpOnly Cookie 识别当前浏览器，不放在 URL 中。

GET /api/oauth/bind 返回独立 CSRF Token 和提供方、身份尾号。POST 同时校验 Origin、Cookie、CSRF、已有账号密码及确认项，复用密码登录限流。事务内锁定并重新核对凭证、提供方和用户状态，身份创建、凭证消费、会话与审计原子提交。关联冲突不覆盖原用户，临时密码用户需先修改密码。

默认登录策略为空闲 8 小时、最长 72 小时，可在系统设置手动调整。点击和键盘操作更新活动，后台轮询不续期。OAuth 的 5 分钟流程时限独立于登录会话。

## 快照与监控

资源 GET 接口只读取快照。页面提交当前页或单台资源 ID，监控任务按账号拆分，并合并相同实例集合。Worker 按地域、产品分组，最多并发 4 组；只对所选实例查询监控。清单查询同时提供状态、规格及监控所需的产品上下文，不发现额外地域。

任务保存逐实例成功、失败或跳过结果。失败实例保留旧快照，前端根据结果统计数量并重试失败项；刷新中持续显示旧数据及耗时。账号清单同步仍由保存启用账号或手动账号同步触发，Worker 不自主调度周期同步。

系统设置 `auto_refresh` 默认开启，可手动关闭。资源页面按 `stale_minutes` 判断监控缓存，默认 10 分钟；进入页面、重载及页面内到期均可提交刷新任务。成功获取时间保存在实例的 `monitor_refreshed_at`，与云端采样时间、清单同步时间分开。失败不延长缓存有效期，页面至少间隔一个缓存周期再自动尝试，离开页面清理计时器。

账号内最多并发同步 4 个地域。`Cloud.MonitorBatch` 按产品、地域、指标处理，每批最多 50 台实例，并按响应实例 ID 匹配。阿里云服务器监控处理分页和轻量指标元数据。数据库固定查询 CPU、内存、存储空间使用率及连接数，使用相同的快照和 monitor.read 授权。腾讯云复用按指标分批查询，阿里云 RDS 性能接口按实例合并多指标查询。

两家云适配器均复用 HTTP 连接池，批次内的不同指标受控并发查询。同一账号跨地域共享最多 4 个在途监控请求；同接口均匀限频为每秒 20 次，阿里云 RDS 性能查询保守限制为每秒 5 次。分页查询保留顺序，查询结果分别收集后合并，避免并发覆盖指标。

监控展示区分不可用、失败和过期。页面使用实际采样时间判断过期，默认 10 分钟，可在设置调整。任务完成时间不代替采样时间。不能用磁盘 I/O 替代空间使用率，没有挂载点明细时不生成推测数据。平台不安装或管理采集 Agent。

## 任务与进程

默认 `all` 同时运行 API 和 Worker，先绑定 HTTP 端口，失败则不启动 Worker。退出时取消 Worker，等待请求及任务收尾后关闭数据库。

Worker 最多并行处理 4 个不同账号的监控任务。同账号只领取最早的到期任务，其他 Worker 也不能绕过该账号已有租约或更早任务。监控槽位满时不会跳过同账号监控去执行后续操作；服务器操作、清单同步和操作结果核对继续走原来的主循环。

任务使用行锁和租约领取。服务器操作提交前核对权限、云账号和云端状态，先持久化状态再提交。超时或进程崩溃后只核对结果，不重复提交。结果每 15 秒核对一次，超过 10 分钟未完成标记待确认。到期审计清理每小时运行。

API、Worker 和云适配器均拒绝对数据库执行服务器操作。腾讯云普通操作显式 `SOFT`、强制 `HARD`，阿里云使用相应强制参数。ECS 关机保留计算资源并继续计费。

云适配层统一补充错误的接口、真实权限 Action、请求 ID 和脱敏云端说明，并输出结构化 ERROR 日志。Worker 汇总地域发现、资源、标签和监控等全部失败项，写入任务和账号同步结果，页面可展开查看。凭证无效、权限不足、DNS、超时及限流分别显示；API 名称不直接等同于 RAM/CAM Action。

## 验证边界

本地测试覆盖认证、授权、任务去重、缓存只读、批量监控、数据库字段持久化及只读边界。集成测试在临时 PostgreSQL schema 运行。具体执行的检查以对应交付报告或工作流记录为准，不在本文固定测试数量。

云字段映射和请求参数通过模拟接口验证。真实新增云账号、国际站、数据库产品、OAuth2 提供方，以及 Linux Compose 和 Nginx 的实际部署仍需环境联调。产品不内置演示账号或模拟数据回退，暂未接入 LB 和监控历史。
