## 默认地址

| 运行方式       | 地址                    | 执行位置                             |
| -------------- | ----------------------- | ------------------------------------ |
| Docker Compose | <http://127.0.0.1:8080> | 含 `compose.yaml` 和 `.env` 的目录   |
| 发行程序       | <http://127.0.0.1:8080> | 解压后的程序目录，显式设置 `APP_URL` |
| 前端开发       | <http://localhost:5173> | 仓库 `web` 目录，后端另行启动        |

生产访问通过外置 Nginx 提供 HTTPS。`APP_URL` 必须与浏览器访问源一致。
